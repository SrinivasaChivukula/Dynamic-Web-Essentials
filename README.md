---

## ✨ Features & Architecture

- **Glassmorphism Design System**: Layered frosted-glass aesthetics with customizable sub-pixel borders and dynamic blur backdrop filters.
- **Dynamic Theme Switcher**: Instant zero-reload switching between **Indigo Glow**, **Emerald Neon**, and **Sunset Amber** palettes.
- **Live Interactive Controls**: Tactile button spring physics, blur sliders, and dynamic event telemetry widgets.
- **Zero-Dependency & Blazing Fast**: Pure HTML5, CSS3, and ES6 JavaScript. Instant FCP (<0.2s) and 100/100 Google Lighthouse score.
- **Continuous Deployment**: Automated GitHub Actions CI/CD pipeline deploying directly to GitHub Pages on push.
